# hlock v1.0.0 — Specification ("Forge")

> v1.0 is a **breaking release**. There is no backward compatibility with the
> 0.x wire format or library API. The headline: from "lockfile toolkit" to
> **the supply-chain gate for npm** — one binary that verifies, lints, audits,
> and signs lockfiles fast enough to run on every merge.

## 1. Wire format (payload v0x10)

| Change | 0.19 (payload 0x08) | 1.0 (payload 0x10) |
| :--- | :--- | :--- |
| Content id | FNV-1a(`name@M.m.p`) | **BLAKE3-64**, domain-separated: first 8 bytes LE of `BLAKE3("hlock/cid/v1" \|\| name \|\| 0x00 \|\| M.u64le \|\| m.u64le \|\| p.u64le)` |
| Collision handling | silent overwrite | **hard error** `E0106 ContentIdCollision` when two distinct `(name, version)` truncate to the same cid |
| Varint decoding | overlong encodings accepted | non-canonical (overlong) encodings rejected `E0107` |
| Payload strings | lossy UTF-8 (`unwrap_or_default`) | strict UTF-8 `E0108` |
| Digest lengths | 1-byte len wraps mod 256 at pack; unpack demands ≤255 | pack validates len < 256, error `E0109` |
| Digest algorithm ids | ≤3 enforced | unchanged |
| Unknown version | generic error | `E0110 UnsupportedPayloadVersion { found }` with "re-serialize with hlock ≥ 1.0" hint |

Lockfiles produced by 0.x are rejected at parse with a clear migration error.

## 2. Integrity & trust chain

1. **Strict hex everywhere.** The three decoders (strict, lossy-header, lossy-CLI)
   collapse into `hex::decode` which fails on odd length / non-hex digits with
   position-aware errors. Public keys and signatures are never silently truncated.
2. **Base64url is canonical.** Trailing unused bits must be zero; `AA==`-style
   non-canonical tails are rejected. Decode table is a `const` (no per-call rebuild).
3. **Rotation signatures are verified.** `verify_root_rotation(rotation, roots, now)`
   checks that `rotation_signature` is a valid signature by the *old* root key over
   the canonical rotation payload:
   `"hlock/rotation/v1" || new_key_id || new_algo_id || new_pubkey || new_expires || new_role_id || old_key_id || threshold`.
   `verify` / `check` / `ci` fail with `E0306 RotationSignatureInvalid` otherwise.
4. **Clock injection.** `verify_signature(content, trusted, now_epoch)` and all
   expiry checks take the caller's clock; the CLI `--time` flag now governs
   signature expiry **and** trust-root expiry consistently.
5. **Digest is mandatory at the gates.** `verify`, `check`, `ci` fail with
   `E0205 MissingDigest` when the file has no `@digest` line (parsing and
   `deserialize` remain lenient; import/serialize always emit one).

## 3. Policy engine

- `pattern_matches` implements proper prefix globs: `@internal/*` requires the
  `/` boundary; `*` still matches everything.
- Hook and script evaluation share one precedence ladder:
  specific-deny > specific-allow > wildcard-deny > wildcard-allow > no-policy.
- `TrustVerification` is now real: produced by trust-chain validation, consumed
  by `check`/`ci` reports.

## 4. Analysis engine (breaking API)

Free graph functions are gone. One cached structure does all queries:

```rust
let graph = Graph::new(&lockfile);           // O(V+E): name index + cid map + CSR fwd/rev
graph.extract_subgraph(root_names, platform) // O(V+E) BFS, was ~O(n³)
graph.topological_sort()                      // iterative Kahn
graph.detect_cycle()                          // iterative, no stack overflow
graph.transitive_deps(name)                   // O(E) per call, memoized variant below
graph.reachability()                          // memoized all-pairs bitsets for stats
graph.has_dep_path(a, b, filter)              // early-exit BFS
graph.dependents_of(name) / dev_dependents_of / runtime_*
graph.leaf_packages() / dep_count(name) / all_paths_to_roots(a, b, max)
graph.export_dot()                            // node ids are indices (no name@ver collisions)
```

Consumers fixed by construction: `stats` O(V+E) (was O(n²)), `sbom` O(V+E)
(was O(P·D)), `tree` memoized + cycle-safe (was exponential on diamonds),
`merge` hash-based dedup + provenance map (was O(P²)).

## 5. Lazy parsing

`LazyLockfile` v2: package index is **sorted at scan**, duplicate detection is
hash-based (was O(n²)), and the cid→package map is decoded **once** into an
`OnceLock` cache. `get_package` costs one line decode after the first touch;
`into_full` is O(n) (was O(n²) with n BLAKE3 verifications per package).
`into_full` now also carries advisories/vex/licenses (merge parity).

## 6. Serialization

- `serialize(&Lockfile) -> String` — **no `&mut`**, canonical order produced from
  a sorted view of package indices; the caller's data is never reordered.
- `deserialize` collects **all** body parse errors (first 10 reported) instead of
  silently dropping all but the first.
- Capacities pre-sized throughout; `push_varint(&mut Vec<u8>, u64)` zero-alloc
  encoding replaces per-field `Vec` allocation.

## 7. Network layer

- One shared `reqwest::Client` (connection pooling, explicit timeout) for OSV,
  npm registry and scorecard.
- `audit --online` uses the OSV **`/v1/querybatch`** endpoint: one round-trip for
  the whole graph (was one blocking POST per package), with retry + exponential
  backoff (2 attempts) on 5xx/timeouts.
- `outdated` / `fix --outdated` fan out over a bounded thread pool
  (`std::thread::scope`, 8 workers), still deterministic output order.
- Network failures no longer masquerade as "up to date": `outdated` reports
  unreachable packages as `unknown` and `audit --online` surfaces the error.

## 8. Lint registry (single source of truth)

`LintRule` gains `fn metadata(&self) -> &'static RuleMetadata` where
`RuleMetadata { name, severity, category, summary }`. `explain` consumes the
same registry — rule names/severities can no longer drift between `lint`,
`explain` and docs. `explain --list [filter]` renders the table; examples are
rendered in text and JSON output.

## 9. CLI contract

### Exit codes (uniform, documented in every `--help`)
| Code | Meaning |
| :--- | :--- |
| 0 | success (including "nothing to fix") |
| 1 | findings / verification failure / unresolved conflict |
| 2 | usage error, unreadable input, parse error, config error |

### Surface changes
- **Removed**: `info` (use `stats`), `dedup` (use `stats --dedup`).
- **New**: `ci` (verify+lint+audit gate, `--no-verify/--no-lint/--no-audit`,
  aggregate JSON report), `init` (import → digest → optional `--with-trust-root`),
  `trust` (`list` / `rotate`, generating verified rotation records),
  `explain --list`.
- **New flags**: `audit --baseline <file>` / `--write-baseline <file>`
  (no-new-vulnerabilities policy), global `--json` shorthand, `verify --sigstore`
  **implemented** (keyless Sigstore verification via bundle-less Rekor-backed
  lookup is out of scope; `--sigstore` now performs bundle verification when a
  `@provenance` SLSA builder is present, else errors — no more silent ignore),
  `fix --package <name> --to <version>`, `fix --all` honored,
  `tree --root` errors on unknown packages, `--dep-type peer` works on
  `dependents`, `--time` governs signature expiry.
- Every enum-ish flag is a `clap::ValueEnum` (`--color`, `--format`,
  `--dep-type`, `--severity`, `--strategy`, `--algorithm`, `--from`, shell).
  No more silent fallbacks.
- **JSON envelope** for every command in JSON mode:
  `{"schema":"hlock/v1","command":"<name>","ok":true|false,"data":{...},"error":{...}}`;
  errors are JSON there too, with stable codes.
- `NO_COLOR` / `FORCE_COLOR` / `CLICOLOR_FORCE` respected; one styling API.
- **Config is wired**: `[lint] rules/severity`, `[verify] trusted_keys`,
  `[licenses] allow/deny/strict`, `[outdated] timeout/check_major`,
  `[output] color/format/quiet` feed the matching commands (CLI flags win).
  Invalid TOML or unknown `--config` path is a hard `E0901/E0902` config error.
  `hlock config` prints the resolved configuration.

### Diagnostics
All errors carry stable codes (`E----`, unchanged scheme) and, where applicable,
a hint line and a "did you mean" suggestion (Levenshtein ≤ 2) for unknown
rules, packages, shells and flags.

## 10. Performance budget (examples/bench.rs)

Measured on a synthetic 5 000-package, ~20 000-edge lockfile:
`serialize`, `deserialize`, `graph::new`, `extract_subgraph`, `stats`, `sbom`,
`lazy_get_package`. No individual op may exceed 250 ms on the CI runner;
the bench prints a table for regression eyeballing.
